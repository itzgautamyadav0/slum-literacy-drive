## 🚀 How to Run the Website on Your Computer

1. Open your Mac **Finder**.
2. Go to **Desktop** -> **`Bright-Future-Website`** folder.
3. You will see 3 key web pages:
   - **`index.html`** : The clean, modern public landing page for visitors & students.
   - **`volunteer.html`** : The dedicated Volunteer Teacher Shift Registration form.
   - **`admin.html`** : **The Admin Dashboard** where all registered candidate data appears, and where you can click **"Export to Excel (CSV)"**!
